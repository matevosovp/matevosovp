# Классификация токсичных комментариев

Задача: находить комментарии, требующие модерации, контролируя пропущенную токсичность и ошибочную блокировку нормального текста.

## Исходный эксперимент «Викишоп»

Очистка URL/HTML, нормализация, стратифицированный train/validation/test. Сравнение word/character TF-IDF, LogisticRegression и LinearSVC; подбор гиперпараметров и порога, анализ FP/FN.

| Модель | Порог на validation | F1 validation | F1 test |
|---|---:|---:|---:|
| TF-IDF + LogisticRegression | 0,60 | 0,7672 | **0,7817** |

Test: precision **0,7722**, recall **0,7915**, 31 859 объектов. Это сохранённый результат исходного notebook. BERT в нём не использовался.

## Запускаемая версия

[Код](../../portfolio/text_moderation.py): удаление дублей нормализованного текста и конфликтующих меток, split 60/20/20, TF-IDF fit только на train, порог только по validation, итоговая оценка на test.

```bash
python -m pip install -r requirements.txt
python -m portfolio.text_moderation --data data/comments.csv --output artifacts/moderation
```

CSV: `text` и бинарный `toxic`. Нужны оба класса и достаточно примеров для стратификации. Артефакты: `model.joblib` с моделью и порогом, `metrics.json`. Исходные комментарии не публикуются. Новая реализация имеет собственные метрики и не наследует историческую F1.

Тест проверяет полный train/save цикл на синтетической выборке. Для внедрения нужны мониторинг распределения, порог с учётом стоимости ошибок и ручная проверка спорных случаев. Joblib загружать только из доверенного источника.

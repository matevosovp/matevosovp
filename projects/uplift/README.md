# Uplift-моделирование клиентского отклика

Задача: оценить дополнительный эффект воздействия и отличить клиентов, меняющих поведение из-за предложения, от тех, кто откликнулся бы и без него.

В учебном проекте сравнивались SoloModel, TwoModels и ClassTransformation на CatBoost. Использовались стратифицированная кросс-валидация, подбор XGBoost по uplift-метрикам, uplift/Qini-кривые и воспроизводимый inference.

**Сохранённый результат: Uplift@30 = 0,0619.** Это offline-метрика учебного эксперимента, не доказанный рост конверсии в промышленном A/B-тесте. Для сравнения необходимо согласовать определение метрики и схему оценки.

Работа демонстрирует treatment/control постановку, сравнение методов эффекта воздействия и подбор параметров по целевой метрике. Смежные [банковские рекомендации](https://github.com/matevosovp/practicum-sem4-praktika1) решают отдельную задачу ранжирования.
